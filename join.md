<p>
Want to join the GeWoNN Network? Anyone who self-identifies with the <a href="/history-goals">goals and values</a> of GeWoNN can email us to request access to the Discord channel. Please <a href="https://bsky.app/profile/gewonnofficial.bsky.social">send us a private message via Bluesky</a>, and send the following information:
<ul style="padding-left: 1.2rem">
  <li>Your name</li>
  <li>Your current affiliation</li>
  <li>Your current position (e.g., postdoc, doctoral students, master's students)</li>
</ul>
</p>
